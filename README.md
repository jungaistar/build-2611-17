# build-2611-17 · 주간업무보고 자동 생성

생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 17 — 기획 김수준.

> 2026-11-12 번호 변경: 이 도구는 **10번 → 17번**으로 옮겼습니다(내용 · 기능은 v1.1 그대로). 10번은 같은 기획자의 새 요청(심플형 주간업무보고 시스템)으로 새로 만들었습니다. 저장 JSON 의 종류 표기(`build-2611-10/weekly-report`)와 브라우저 저장 키는 예전 파일과 맞추려고 바꾸지 않았습니다.

**바로 쓰기: https://build-2611-17.jobability.co.kr/**

팀원별 금주·차주 업무일지(엑셀 표 또는 붙여넣은 표)와 지난주 주간업무보고서를 올리면
업무마다 지난주와 비교해 신규·계속·완료·지연을 나누고, 비슷한 업무를 통합하고,
**복리후생/총무 · 사회공헌/의전 · 자산 · 비상계획** 4개 업무 분야로 자동 분류해
Ⅰ 전체 업무 요약 → Ⅱ 분야별 금주 추진실적·차주 추진계획 → Ⅲ 종합 관리사항 순서의
팀장 보고용 주간업무보고서(인쇄·HTML·엑셀)를 만듭니다(v1.1).
분류가 확실하지 않은 업무는 「분류 확인 필요」로 두고, 화면에서 고치면 다음 주에도 같은 업무명이면 그 분류를 먼저 씁니다.
이번 주 결과는 다음 주의 「지난주 보고서」로 저장해 이어 씁니다.
규칙으로 동작해 API 키가 없어도 되고, AI(선택)는 요약 문장만 다듬습니다.
파일은 브라우저 안에서만 처리하며 서버로 올라가지 않습니다.

| 파일 | 역할 |
|---|---|
| `js/report.js` | 판정 엔진(읽기·정규화·유사도·구분·**업무 분야 분류(`FIELDS` 낱말 표)**·일정 변경·이슈·Ⅰ Ⅱ Ⅲ 보고서·내보내기·AI 요청 모양) — 판정은 전부 여기 |
| `js/app.js` | 화면 |
| `test/logic.test.js` | 판정 규칙 테스트 `node test/logic.test.js` |
| `test/smoke.browser.js` | 화면 연기 테스트(playwright) |
| `CLAUDE.md` | 작업 지시서 + 기획서 원문 |

예제 데이터는 실제 사내 데이터가 아닙니다.

## 업무 분야별 보고서 (v1.1)

- 분야 4개는 고정 순서입니다. 업무명에 든 낱말 3점·추진현황/이슈/목적의 낱말 1점으로 점수를 매기고, 1위가 0점이거나 2위와 2점 미만 차이면 「분류 확인 필요」로 둡니다.
- 우선순위: 화면에서 고친 값 → 업무일지의 `분야` 열 → 지난주 보고서의 분야 → 자동. 고친 값은 브라우저(`localStorage`)와 저장 JSON 에 남습니다.
- 분야 분류와 구분(신규·계속·완료·지연) 판정은 따로 돕니다. 한 업무는 한 분야에만 들어갑니다. 업무가 없는 분야도 「해당 기간 업무 없음」으로 남깁니다.
- 낱말 표를 늘리려면 코드가 아니라 `js/report.js` 의 `FIELDS` 를 고칩니다. v1.0 에서 저장한 JSON·엑셀도 그대로 읽힙니다.
